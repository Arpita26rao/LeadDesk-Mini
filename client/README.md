# LeadDesk Mini

A full-stack Lead Management application built for the **Digital Heroes Internship Task**.

## 🚀 Features

- User Login (JWT Authentication)
- Lead Submission Form
- Admin Dashboard
- Search Leads by Name & Email
- Lead Status Management (New → Contacted → Closed)
- MongoDB Database
- Responsive UI
- Client & Server-side Validation

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication

---

## 📂 Project Structure

```
LeadDesk-Mini/
│
├── client/
└── server/
```

---

## ⚙️ Installation

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```
